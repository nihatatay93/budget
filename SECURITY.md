# Security Policy

## Supported versions

Budget has not published its first stable release. Security support begins with the first
public release and will be documented here by version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for the public `nihatatay93/budget` repository once it is available.

Include the affected version or source revision, reproduction steps, impact, and any known
mitigations. Please avoid accessing data that is not yours or disrupting a running service.
